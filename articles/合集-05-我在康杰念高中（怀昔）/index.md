# 我在康杰念高中（怀昔）

> 作者: 凡复思忖 | 日期: 2026-03-05

<p><img class="article-cover" src="assets/images/articles/合集-05-我在康杰念高中（怀昔）/cover.png" alt="我在康杰念高中（怀昔） 封面"></p>




触碰到了最底层的记忆。像是老旧的相片匣被打开，积压的照片一瞬间找到了释放的方向，猛地向上弹出，如雪花般四散在空中。

去年今日此门中，人面桃花相映红。人面不知何处去，桃花依旧，笑春风。

可是那个地方已经没有人了。

![](assets/images/articles/合集-05-我在康杰念高中（怀昔）/001.jpg)

我的班主任是柴海军老师，语文老师，有一代大儒风范。他刚带完我哥的高三班，转头回来带高二。后续两年都是他带我们。从小到大我第一次见到这种范儿的老师，说话慢条斯理又很有逻辑，嗓音温柔却带着威严，手底下也是真硬，之前带的班里着实出了不少的年级前几。

刚开学时学校举办迎新晚会。当时和我坐得比较近的RLY报名参加了。演的啥我忘了。但我献殷勤给她留了个凳子。以前初中的时候喜欢踢球，每天踢完也没地儿洗澡，两周才能回一次家，回家搓澡时总是一地泥，脖子上一划拉就是一道。当时也对女孩子没什么兴趣，成天就是看书+踢球。得益于厚厚的一层泥膜，也没怎么晒黑。上了高中时，却对RLY产生了很大的兴趣。

老班给我们分配了学习小组，按照成绩从前往后，按照加10的方式选人。例如第一名，第十一名，二十一名，以此类推。第一次我是跟LMX，LN，RLY等人组成的。我是组长。于是我就提议和RLY做同桌。LN也是河津人，也坐我边上。现在想想真挺对不起兄弟们的。

以前年纪小不懂事，不太会追女孩子。在单纯的学校环境下想的也很简单，只要我学习成绩最好，班里最强，不就有一万个理由接近她了嘛。回去还跟LQJ，SYM讲了讲这个事情。

那时候竞选班长，最终HYQ当了正的，我打下手。有一次跟大家宣讲高二要认真学习的时候，SYM就在下面起哄，用非常暧昧的声音说：“要定好一个目标。”这里的目标，对我来说，就是RLY了。做同桌总是有很多接触的机会，我记得她跟我讲龙族，路明非。我当时没看过，非常可惜，后来去看了，也不怎么看得下去。江南的作品我也就看了看此间的少年。

第一次的元旦晚会，RLY报名了唱歌节目。我跟HYQ出去一顿采购，为大家做好后勤工作。轮到RLY上场的时候，SYM推我，让我上去送花。可是当时羞涩的我，没能起身，被另一个同学抢了先。

初开的情窦飞速结束于高二的第一个寒假。虽然感情失利了，但那时我已经足够强大，有机会去考到全班第一，全校前百了。我们班是个普通班，上面有六个重点班。我在重点班里面只能排到第十几名。以我现在的眼光看，当初的我简直就是不入流，还有很长的路要走。

下半学期刚开学，又要开始调整座位了。我跟老班建议说，我们可以按照成绩的先后顺序让大家选座位，高一时候的班级就是这么干的。老班采纳了我的建议，正是这样，我才能陪伴LLQ很久。

LLQ坐在我的正前方。我觉得这个姑娘大大咧咧的性格很好，课间玩的时候说自己头比较平，可以顶起一摞书，说罢还给我表演。给我笑得合不拢嘴。我跟她讲我对RLY的情思，她们是好闺闺，于是她大咧咧说要帮我接近。殊不知，在不断的接触中，我的情思早已转到了她身上。

要重新安排座位的时候，我问LLQ，你，要不要跟我在接下来一年半里一直做同桌。她几乎没过多犹豫就答应了。每次我都问她想坐哪里，然后我第一个去选。碰到有人想选我身边的时候，我赶忙弯腰作揖，求着大伙儿给个面子。我的同学们人也都很好很好，几乎每次都能让我等到LLQ。

那时候SSL，YXX，我们几个坐一块，每天玩的也非常欢乐。SSL超级会唱歌，喜欢王力宏，甚至不会日语的情况下，可以唱出青鸟（火影忍者）。时不时睥睨我们，你们懂这种摇滚吗？王力宏的火力全开。他跟LC会经常合唱，“丢掉背包，丢外套，丢掉大脑，再丢烦恼”。

YXX的缘分跟我有点儿深，后来发现，她很像我大学时候女友的妈妈，古典美女一枚。她是我唯一的笔友。我在大学时和正在奋战第二次的她用信件交流。玩游戏输了的时候，惩罚是抱头蹲墙角唱国歌。很遗憾，她接受过一次惩罚。

时间说慢也是慢的，日头淹没在题海中，说快，像是骏马扬鞭，倏忽之间就过去了。

LMX是第一届的团支书，非常板正，做课间操的时候数他做得最标准。而且非常擅长于用一本正经的语气跟你开玩笑。GQT他们喊他阿木，我延续了初中的习惯，喊他老木。他跟ZXG还是亲戚关系，虽然我以前没怎么见过，但一直都知道这个名字。以前穿衣服，妈妈喜欢给我买美特斯邦威的，我的蓝色格子衫就跟ZXG的粉色格子衫，成了情侣装。后来我们商量，每人穿一周好了。

LQJ开始的时候像杀马特，头发很长，说话拽拽的。而且有个同样酷酷的女朋友。SYM一开始只是高，大家并没有觉得他很帅。后来听人喊他高富，给我乐了好一阵子。我觉得他是帅的，帅玉米。下一届的团支书就成了WYT，大家都喊她团长。我时常会在群里发一个超级大的捂脸表情，于是团长带头第一个喊我大脸，实际上我的脸是不大的。

每天跑早操的时候，大家都起得晚，在超市门前等着自己班的队伍前来，加入队尾。跑课间操的时候，大家也都不下去排队，等排好了出发了，再从教室里面飞奔出去，到必经之路上等着加入。我跟SYM经常干这个事，轻车熟路，每次都能多做两道题，节省了不知多少时间。

我跟LLQ做同桌的时候，大家拿的手机都已经可以玩QQ了。她的QQ名是没有如果，喜欢梁静茹。我们经常互发短信，记得在一个周六的夜晚，她说窝在妈妈身边看电视。我发短信告诉她我在教室刻苦用功。那个夜晚的风，一直吹拂我到今天。

高二时候，我拥有了一台视频播放器，就在宿舍里面看亮剑。我清楚地记得那周是清明节，我每天晚上看到凌晨4点，白天继续去学习，睡眠严重不足。清明回家上坟的时候，我跪在最前面，等我爷爷烧完纸，大家磕头起身。我起身的时候只感觉一阵天旋地转，摔倒在了火坑中，吓得大家赶忙把我扶起来，让我回去休息。那是我最后一次在村里上坟，之后高三以及大学，就再也没回去过。

我从高二后期开始跟大家去网吧打游戏。那时候LOL刚起步，我就问ZWP，你能不能带我去通个宵。ZWP上下打量我一眼，显是不信的样子。我还是死皮赖脸地跟着他们去玩。那时候LQJ，SSL，LYF他们玩得比较多，后来SYM，GQ，DYC，DRX都加入了。相比于他们，我就是个新兵蛋子。大家的ID也起的很有意思，飘逸星辰血，月ligh, 沃特麦勒，末日小然，海之道等。

大家打LOL经常五黑，被人机虐得体无完肤，但是又很快乐。后来状况愈演愈烈，玩的人越来越多，大伙儿玩的时间越来越久。雷达街网吧的座位都快要不够用了。我们比较喜欢去新世纪，最新装修的网吧，有二楼有包间有后门，环境很好。那时候去网吧玩，还问LLQ想不想吃大盘鸡，会去的时候给她带。唯一带的那一次，洒在了包里，回去就没汤了，只剩下面，但她依然吃的很开心。

那年夏天，有个什么专项行动，要求所有的网吧晚上不能提供网络，不让大家通宵。我们听说路口有家网吧晚上有网，于是纠集了7个人一起去。7个人打了一辆车，前座一个，后排挤六个。最后下车时，司机不高兴，想多要钱。SSL非常霸气，甩给他一张5块就走了。

我们的教室窗户虽然是可以锁上，但是只要懂得技巧，轻轻往上一提，就能打开。因此经常可以看到，门还锁着，里面已经坐着人的情况。夏天的时候，我跟LYR提前回学校，先在市区看了电影。回来的时候已经很晚了。我先进了自己的宿舍，过会儿LYR告诉我说她进不去门了，宿管已经把门关了。没办法，我带她去找LZW，借住一宿。回来的时候，宿管不让我进门了。

哎，这是中国一些基层掌权者的悲哀，完全凭借自己的喜好，将权力发挥到极致。我跟阿姨说，阿姨我刚刚还在宿舍里面，是我一个同学没地方住，我出去帮了她一把，还是你帮我开的门呢。阿姨根本不听我解释，只说我出去的时候没关门，死活不让我进。我进不去宿舍，只好去操场躺了半夜。躺到早上4点的时候，再回到自己班教室，把桌子拼好，再睡到早上8点。餐风露宿也不过如此。

高三后大家的生活就发生了一些变化。我原本是住校的，后来在非常空间租了个房子，办了走读证，每天就回去住。其他住在校内的同学就是翻墙。记得有一次上网玩太High了，早上才回到教室，挨到中午回去睡觉，睡前担心自己起不来，跟ZZC讲说中午走的时候喊我一下。没想到他叫我的时候我睡得太沉，没有起来，他就走了。等我睁开眼的时候，是晚上10点了。那是人生中第一次睡了一整天。我这算好的，有一些同学上网回来的时候，迎面碰上了老班，吓得躲进花丛中等老班走远。

我跟LLQ的关系一直还不错。但当时我知道她跟PSR，我的高一舍友有一些瓜葛，再加上她以为我likeRLY，所以我们并没有什么进展。但依然发生了许多令我难忘的事情。我中午在教室睡觉时，听到她到了教室，过了一会儿一件校服就披在我身上。我当时并没有睡着，也没有动弹。从那之后我每天都在教室睡觉，一直趴到她来上课。不过再也没有被披过校服。后来她帮我洗过一次校服，略作补偿了吧算是。

又到了一年元旦晚会，LLQ约我合唱被风吹过的夏天。我就去网吧下载了歌曲歌词，每天不断练习。但由于我天生唱歌不好听，初中时就有这个问题，还被音乐老师diss过。那之后我对于唱歌非常抵触。但由于是LLQ，我还是鼓起勇气，试图克服困难。

到了元旦晚会当天，我没有勇气上去。LLQ独自上台完成了演唱。当时我挺任性的。哪怕是上去假唱也行啊，不要让她一个人暴露在风雨中。但情绪上头的时候，人就是会做出一些出格的举动。那天晚上比较乱，她的椅子也找不到了，我就把我的椅子换给她，她不要，赌气，晚上回宿舍时，我就不远不近地跟着，内心五味杂陈。大家在喜欢的人面前往往过于拧巴。

当晚还有个三部的哥们，接受不了自己情感的失败，跑来俺们班闹事。事情起因是SYM和LZW在一起了。LZW是双胞胎姐姐，从小学声乐的，性格也很好。喜欢她的人排到了三部。三部那个哥们纠集了一帮人，喝了点破酒，就来我们班闹事，喊SYM出去。这样的失败者根本不值得人同情。我只记得他不如SYM高，帅，还比SYM胖。那我要是女生，我眼睛也不瞎啊，接受自己失败有那么难嘛。

我每天早上会给LLQ带个鸡蛋灌饼，或者是妈妈做的早餐。我记得她挺喜欢吃。高三期间LQJ和LHN的家长还被叫到了学校，让处理一下孩子们的早恋情况。我们一起在周六的夏夜做过游戏，记得当时输了的人大冒险，由于LHN性格直爽，像个男生，那段时间空虚寂寞冷很流行，我提出的大冒险就是：在楼道里喊我空虚寂寞。。。

我们班里还有一对模范情侣，XKK和NCY。他们很早就在一起了，而且也很甜蜜。大家都觉得他们会一直幸福地生活下去。除此之外，一些人的选择跟大家就有了偏差，许多同学去走艺术路线，例如HYQ，LXL她们。现在想来，艺术生也很好啊，掌握一门独属于自己的技艺，在漫长的人生中根本感受不到孤单寂寞。

我高二高三的时候学习非常猛。猛到什么程度呢？语文英语都是以考代学，从来只学习数学，物理，化学，生物。记得有一次月考，生物选择题有40个，那次大家都做的不太好。我只错了一个。在路上我都被人看到了，听他们窃窃私语，说那个人生物这次考了快满分。

学到椭圆和方程的时候，由于计算量大，一开始我也摸不着头脑。下午去网吧玩了一会儿，回来后，再看那道题目，立刻就会了。很神奇，也许是我的潜意识不断地在做那道题。总之数理化我根本不带怕的。语文英语从来都是考试的时候复习一下，绝不多给额外的时间。导致我语文英语一直不好。永远维持在110分左右，不上也不下。

SYM，LZJ数学也很猛。我觉得他们非常地聪明。许多问题一眼就看透了本质。但是SYM的语文成绩很拉，谁能想到，后来高考考到同济的人，语文都没及格。这要是换成俺的语文成绩（虽然也不高），成就不可限量啊哈哈。

我很爱背诗词，除了课本上的，我还额外背了许多课外的。每次考试的时候，我如果早早就写完了，就在草稿纸上疯狂写诗词，重复写，继续加深印象。我很喜欢考试，尤其是考前一小段时间，大家都疯狂学习，我就偷得一段闲暇时光。考完后大家也都匆匆忙忙去上网。

记得有一次，我们周六准备通宵。SYM要带LZW回去，由于宿舍进不去了，我就让他们回我家。但是我家门比较难打开，他们折腾了很久没搞定，动静引来了邻居奶奶。邻居奶奶后来给我妈告状，说我带女孩子回家。实际上我早跟我妈妈讲了事情的前因后果了。

一次月考结束后，晚上7点多回宿舍找同学玩。听到一阵悠扬的歌声，“如果你对天空向往，渴望一双翅膀，放手让你飞翔”。是LXJ在唱歌，他的嗓音条件真的是不错，这首歌我也记了好久好久。

高三开学后我们换了物理老师，胡俊，看起来是刚毕业不久，人很帅，讲课风趣幽默。跟我们讲到流体的时候，举例子说，加入你在公交车上，公交车往前走了，你原来的位置就填了一个跟你一样的空气人，这样的过程不断地重复。啊，讲起事情来可以跟实际相结合，把枯燥的物理知识化用到生活中。

我考试的时候，经常坐在前几个考场。有一次我和YM，574的班长坐了前后桌。但我当时并不敢搭话。想着下次如果再坐一块，再说话好了。后来上化学课时，我就问化学老师杨春苗老师，说你们班的YM巴拉巴拉的。苗姐说，你可别打人家的主意啊，人家可是要好好学习的。YM的确是拿到了最高的学历。而苗姐，已经癌症去世很久了。

LLQ送了我一块表作为生日礼物，同时也感谢我那么久以来给她带饭。圣诞节前一天晚上，我梦见了她，于是想约她去操场走路。而她正好和XRM洗完澡回来，在宿舍门口碰到了她们两个。我没有好意思当面提，回家之后才发短信，她回应我说应该悄悄跟她说，她就让XRM回去，她跟我走的。

最后一段时间大家的学习压力都很大。我也是。在某一天，我跟LLQ表白了。被拒了。心情极度压抑，每天回家的时候，跟ZZC走在路上，我都哭一路走回去。ZZC也不知道如何安慰我，于是把我这个情况说给了LJM，LJM又传达给LLQ。第二天早上，我坐在座位上时，LLQ就来，满眼笑意地问我，最近是不是心情不好。我原本心情是不好的，但是她来问了我，我就好了一些。她又问我要不要继续坐一块，我点了点头。于是最后一段时间，我跟ZZC，LLQ，LJM坐同一排。我跟LLQ坐在两侧，ZZC和LJM坐在中间。

在这里，我再感叹一下中国学生的压抑吧。我跟LLQ不讲话之后，有一次背书时，听到隔壁两个哥们在低语，说刚才在这里的那个女生好好看啊，去要个联系方式。我一阵白眼，他们说的就是LLQ，还在我面前说，已有取死之道（小说手法，玩笑，玩笑）。

不知何时起，刮起了一阵羽毛球风。每到课间操的时候，大家都拿着拍子出去挥杆。我跟LZJ打球的时候，有一次用力过猛，球直奔着小姑娘的脸去了。她连忙拿拍子挡着，但力道太大，拍子在她脸上留下了红印。从此之后我就欠她一张脸。

我的闹钟是追梦人。每天晚上1点多睡，早上5点半，闹钟就响起。但它只能唱几句，到“已记取了你的笑容”。后续我没有听到过。因为这时候我已经醒了。披星戴月。

到了快要高考的日子，班长HYQ在黑板上，留下了一些话语，感叹之后很难再见到大家了。然后让猜猜她是谁。拜托，每个人说话的语气不好改，一眼就猜出来了啊。

老班给我们讲了最后一节语文课。用心学习，收获生活。认真做事，体验生活。面对现实，品味生活。培养兴趣，感恩生活。不要让自己的大脑成为别人思想的跑马场。我已经30多岁了，生活的经历已经将我眼中的精光抹去，整个人都从容温和了许多，这些话语还是常伴我左右。

我们还举办了毕业典礼。大家在典礼上都哭成了泪人。在彼此的衣服上，签下名字。那件写满了所有人名字的短袖，现在还躺在我的衣柜深处，虽然有点发黄了，但是名字依然清晰。

![](assets/images/articles/合集-05-我在康杰念高中（怀昔）/003.jpg)

6月7号，神圣的时刻已来到。考前，我坐在操场上，给班里每个同学都打去了一个电话，有的人没接到。接到的，我都向他们送了祝福。那段时间特别爱看武侠，金庸封笔古龙逝，江湖唯有英雄志。一直想象我们这些人毕业后可以去建功立业，领略大好河山的壮丽。在这赶赴战场的前夕，想跟大家再说说话。

电话打到RLY的时候，她说两年没说话觉得挺对不起的。我表示不介意，说到时候考了多少跟我讲一下就好了。但也没等到她跟我讲。现在是真的不介意了。人与人的缘分就断在过去的某天了。

高中两年很快就过去了。有许多的恩怨情仇，最后大家也都泯然一笑。SSL和XRM也没法说话了，我帮SSL要了一张一寸照片，留作最后的念想吧。这么些年来，高中时期的好友也不是每个人都有联系。但是共同的记忆永不磨灭。

再往后啊，故事有许多的延续。很多事情我进一步知道了，但更多的是我不知道的。我所关心的人们，大家也都过得很好。谢谢大家的出现，一起相互扶持，走过了那段最难熬的岁月。人生到头来，不就是一场体验嘛，身外之物生不带来死不带去的，唯有这些珍贵的记忆，是永远的精神力量。

如果还有什么想对这些人说的，那就是，不然大家再回573，把高考答案一起对一下吧？
