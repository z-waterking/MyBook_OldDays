# 粉丝投稿

这里存放粉丝投稿的公开成稿、编辑评价和编辑说明，与作者个人文章档案分开维护。

## 目录约定

- 每篇投稿使用独立目录，命名为 `粉丝投稿-编号-标题`。
- `index.md`：以公众号已发布版本为准的公开成稿。
- `review.md`：投稿专栏内部评价，不并入作者个人文章总榜。
- `notes.md`：内容摘要、编辑处理、事实核对项和配图提示词。
- 正文图片集中放在 `assets/images/fan-submissions/<投稿目录>/`，正文使用仓库根路径引用。

## 发布约定

确认发布后，以公众号成稿为权威版本归档于本目录，并在 `website/submissions.md` 手工增加编号、简介和公开入口，再重建站内搜索与图片索引。投稿可公开检索，但不加入作者个人榜单或成书结构。涉及资产、违法行为和第三方指控的内容保留“投稿人自述、未经独立核实”说明。
