## 编辑原则

1. `articles/` 是档案，不轻易改动；`book/` 是成书结构，可以重排、删选和增补。
2. 正文书保留沉浸阅读体验，评价版本保留在网站档案中。
3. 每卷应有一篇导言，每篇应有一句短说明，方便读者进入时间、地点和语境。
4. 后续新增文章优先补“研究生时代”和“正式工作初期”，它们是当前人生线中最明显的空缺。
