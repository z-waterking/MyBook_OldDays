## 编辑原则

1. `articles/` 是档案，不轻易改动；`book/` 是成书结构，可以重排、删选和增补。
2. 正文书保留沉浸阅读体验，评价版本保留在网站档案中。
3. 公开阅读页只展示已完成文章；待写题库、删选理由和风险说明统一放在编辑规划中。
4. 每部有一篇导言，每篇有一句短说明，帮助读者进入时间、地点和语境。
5. 新增主篇优先补研究生时代、正式工作转折和全书尾声，它们是当前人生线最明显的空缺。
6. 正式出版前必须统一人名、公司称谓与时间线，并对实名职场叙事做事实、隐私和名誉风险审读。
